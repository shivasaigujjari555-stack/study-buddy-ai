# Study Buddy AI 📚

**An AI-powered student productivity platform built to make learning smarter and more organized.**

Study Buddy AI helps students manage their academic activities through AI-powered study planning, note generation, quizzes, timetable management and machine-learning-based performance insights.

## 🚀 Features

- 📅 AI-assisted study plan generation
- 📝 AI-generated study notes
- 🧠 Automatic quiz generation and assessment
- ⏰ Timetable and task management
- 📊 Student learning-performance analysis
- 🤖 Machine-learning-powered insights

## 🛠️ Technology Stack

| Component | Technologies |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Node.js, Express.js |
| Database | MySQL |
| Machine Learning | Python, FastAPI, pandas, NumPy, scikit-learn |
| AI Integration | OpenRouter |
